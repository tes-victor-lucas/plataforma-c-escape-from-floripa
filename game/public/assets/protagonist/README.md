# Protagonista LPC — referência visual

Spritesheet de caminhada (8 quadros × 4 direções, quadros de 64 × 64 px) do
protagonista inspirado nas referências fornecidas: homem adulto de cabelo curto
escuro, camisa polo azul de manga longa, jeans claros e sapatos marrons.

Configuração no Universal LPC Sprite Sheet Character Generator:

`male / Body_Color_light / Human_Male_light / Neutral_light / Side_Parted_w-Bangs_black / Longsleeve_Polo_blue / Long_Pants_sky / Basic_Shoes_brown`

Gerador: https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/
